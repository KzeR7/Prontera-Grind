Set a local GM password

The game's GM tab is unlocked by logging in as GM. On a preview server there is no server-side GM account, so this page writes the game's local GM door (pg_gm_local) into this browser. You pick the password; nothing is stored here or in the repo.

checking…

Then log in:

  1. Open the game → (that is /game — the preview root / is this page right now)
  2. Username GM, password the one you just chose
  3. The GM tab appears in the dock. For testing the attack animation you want: +10 Lv a few times, or Unlock Nightmare (jumps to Base 150 and opens every map), then spend the stat points on AGI — that is the fast-attack build where the swing/number drift used to show.

Prefer the console? On the game page this is the same thing:

localStorage.setItem('pg_gm_local', gmHash('test1234'))
Remove it with localStorage.removeItem('pg_gm_local'). The game's own GM_PASS_HASH is separate and unchanged by either route.
