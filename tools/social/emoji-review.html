And that research found a serious problem with the PR. Its action numbers are wrong for all 32 real ones — it maps omg to action 86, but /omg is ET_HUK at action 23. None exists in RO1's emotion.act/spr, which is this game's only emote source — so there is no picture to show. Each card states the true action, the true ET_ name and the PR's claim so you can check it yourself.
