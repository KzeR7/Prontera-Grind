What this page is. Three ready-to-apply styles for the combat numbers, plus the restored critical "explode frame" that v66 had and v67 removed, a brand-new skill-critical animation, and live font / size / fade controls so you can dial the look in before anything is applied. Fire a volley with the buttons (or press Space), switch tabs to inspect one option up close. Research this is based on

  • Classic RO: damage is drawn with the client's own digit sprites (NewNumber.spr / damage number textures) that pop above the target and fade; a critical hit "usually has a red spike bubble around the damage" — that burst is exactly the frame that v66 had and v67 dropped.
  • WoW's crit pop is a 3-stage scale (small → big → medium) — the overshoot-then-settle punch used by every option here.
  • Gamedev consensus (r/gamedev "making good floating damage text", Godot FCT recipe, Unity FCT write-ups): always move numbers vertically so new hits aren't hidden, add a small random spread so hits don't stack, scale-punch on spawn, fade near the end of life, keep crits bigger with extra punch, colour-code damage types sparingly, and merge fast DoT ticks into one refreshing number instead of a cascade.
  • Readability: a hard dark outline (not a soft shadow) is what keeps digits legible on bright maps; every option keeps the game's outlined-text approach and adds a hold-then-fade curve instead of today's linear fade.
