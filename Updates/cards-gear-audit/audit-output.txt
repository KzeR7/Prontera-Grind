1. CARD VALUES  (cardVal(g,stat) = round(CV[g] * AB[stat]))
====================================================================================================
grade       CV         STR         AGI         DEX         LUK         INT      Max HP       ATK %      Crit %      ASPD %      Flee %  Crit DMG %
Common     1            1         1         1         1         1        12         1         1         1         1         2
Uncommon   2            2         2         2         2         2        24         2         1         1         2         3
Rare       3            3         3         3         3         3        36         2         1         2         2         5
Legendary  5            5         5         5         5         5        60         4         2         3         4         8

pool: Common/Uncommon roll only str/agi/dex/luk/int   |   Rare/Legendary roll all 11 stats
a card fits ONE group (CFIT): str->weapon dex->weapon atk->weapon crit->weapon cdm->weapon agi->armor aspd->armor flee->armor vit->armor int->head hp->head luk->acc

where each grade drops (fieldOf): stages 1-3 Common, 4-7 Uncommon, 8-9 Rare; Stage-10 boss Legendary
  field card: Common     0.45% per kill
  field card: Rare       0.45% per kill
  boss  card: Legendary  0.08% per boss kill
  the rate never changes with stage or map - only the grade does

what stat each map's boss card actually rolls (cardStat(3,m) - it is FIXED per map):
  Prontera=str  Izlude=agi  Geffen=dex  Morroc=luk  Payon=int  Comodo=hp  Louyang=atk  Amatsu=crit  Niflheim=aspd  Abyss=flee
  field (mob) cards are fixed too: per map + stage + mob, e.g. map 6 stage 8 mobs roll 11 stat slots seeded by (map*10+stage+mob).

  Common     1         1.00     2.00     3.00     4.00   1
  Fine       1.6       1.60     3.20     4.80     6.40   1-2

  Epic       4         4.00     8.00    12.00    16.00   2-3
  Legendary  6.5       6.50    13.00    19.50    26.00   3

affix value = round(af x AB[stat] x rnd(0.8,1.25)); expected value shown (x1.025):
stat           sec0-3 Common         sec1-2    sec2-3 Rare      sec3 Epic sec3 Legendary
  ATK %                    1              3              4             10             16
  ASPD %                   1              2              3              7             12

  Max HP                  12             39             64            148            240
  ("sec3 Epic" = Amatsu/Niflheim/Abyss field drop; "sec3 Legendary" = Stage-10 boss drop)

=> ONE endgame legendary drop can carry 3 affixes, and every one of the seven slots
   rolls from the same pool, so the same percentage stat can stack seven times.

5. THE DROP FAUCET
====================================================================================================
  Prontera  stage 1:  9 items in the pool, 3 gear rolls per kill at 4.8%/4%/3.2% = 12.0% per kill
  Payon     stage 1:  7 items in the pool, 3 gear rolls per kill at 4.8%/4%/3.2% = 12.0% per kill
  Louyang   stage 1:  9 items in the pool, 3 gear rolls per kill at 4.8%/4%/3.2% = 12.0% per kill
  Abyss     stage 1:  9 items in the pool, 3 gear rolls per kill at 4.8%/4%/3.2% = 12.0% per kill
  Abyss      stage 10: boss drops the whole pool (9 items) at 2.4% each = 21.6% per boss for a Legendary item, plus 5 escorts at 4.8/4.0/3.2% each
  every stage-10 boss drop is Legendary (tier 4) whichever map it is on
  sell: 1,825z for an item that is worth more than any drop on maps 1-6
  refine: 200z (r0) -> 5,000z (r9) + 1 ore per ATTEMPT, success 100%/100%/70%/60%/40%/20% for r0/r3/r4/r5/r7/r9
  a failure consumes the ore and the Zeny; at +5 and above it also drops the item one level (it never breaks)

  expected cost to FIRST reach each refine level (high-tier item, one sample per item):
    +5:    5.4 ores       8,568z
    +6:    8.1 ores      15,961z
    +7:   12.6 ores      30,268z
    +8:   22.1 ores      61,996z
    +9:   47.6 ores     150,978z
    +10:  153.9 ores     530,672z
  one stage-10 wave pays ~0.30 ore (of either kind), so +10 on ONE item = 513 boss waves; a whole 7-slot +10 set = 3591 waves.
  (+0..+4 is ~11 ores total - that part is cheap. The +9 -> +10 rung alone averages 106 ores.)
