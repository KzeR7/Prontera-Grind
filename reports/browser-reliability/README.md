## What changed

- **Same engine, same license, same SRI.** The game now uses the r128 file already shipped for map exploration (`assets/endgame/three-r128.min.js`, SHA-256 `9274bbcec8d96168626c732b5d31c775aa8cfb7eaa0599bec0c175908a2c1ce2`). Classic parser-ordered scripts still load the library before GLTFLoader, then the game. No CDN fallback, version upgrade or extra published engine. If the required script itself fails, sign-in stops before starting a character, recovery remains wired, and Retry startup reloads. The local staging archive includes the matching build dependencies.
- **Field.** Both renderer construction attempts can fail. Pointer binding, resize, projection and drawing now handle that state; account and menu handlers are no longer stranded below a null dereference. Field loss still prevents the event default, saves/flushes, and restores the same renderer. A manual graphics refresh uses the existing save-confirming refresh flow, not an unconditional reload over pending progress. The field notice doesn't cover the plaza.
- **Plaza.** Try a non-antialiased context if needed. Surface graphics status separately from chat, suspend rendering while lost, and resume on restoration. No duplicate scene/renderer on ordinary leave/re-entry. Limit asset initialization to 45 seconds; on failure release the partial renderer/context, remove its canvas/labels and release the entry lock. Leave to Field and re-enter to retry; persistent context loss also offers save-confirmed refresh. Native field loading already had its own six-second scenery fallback.
- **Hit testing.** Reserve space in the phone plaza toolbar's first row for the Quests chip; its sheet clears the measured toolbar. Do not drop its z-index below the scrim (it must still close the sheet). Keep the desktop and field layouts. The existing plaza raycast uses the displayed bounding rect; the field camera uses pointer deltas. No user-agent checks or speculative coordinate rewrite.
- **Networking/storage/cache.** Start the existing cloud probe on DOMContentLoaded; retain the normal auth deadline, cookie checks, ownership and save/outbox logic. A synchronous WS denial uses existing backoff and no longer prevents solo scene creation. No new Social message, heartbeat, endpoint or alarm. Versioned assets and all build labels move together. Explicitly revalidate `/` as well as `/index.html` and `/version.txt`; the v426 generated header file didn't name `/`. **No evidence that stale cache or blocked storage was the cause of the original player reports.** Local server sends `no-store`; actual hosted CDN reuse was not measured. No site data is cleared.
